プライバシーポリシー / Privacy Policy

openclaw-gog は、所有者本人の Google アカウントだけを対象にした個人用ツールです。

  • Gmail・Google カレンダー・Google ドライブの読み取りの権限（readonly）だけを使います。送信・変更・削除はしません。
  • 読み取ったデータは、所有者のサーバーの中で、所有者の質問に答えるためだけに使います。
  • データを第三者に販売・提供・共有しません。広告にも使いません。
  • Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。
  • 許可は Google アカウントの設定（サードパーティ製のアプリとサービス）でいつでも取り消せます。

openclaw-gog is a personal tool used only with its owner's own Google account. It requests read-only access to Gmail, Google Calendar and Google Drive, and never sends, modifies or deletes data. Data is used only on the owner's server to answer the owner's requests, and is never sold, shared with third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account settings.
